In this repository (the user's Licenciatura thesis project at ITeDA), Spanish is reserved strictly for the thesis corpus itself — `Tesis - Latex/` — since it's a FCEN-UBA thesis and must read as a single, consistent Spanish document: any new prose, revised sections, or figure captions added there should stay in Spanish to match. Everywhere else, the user wants English: chat replies, review notes and reports, `.md` files, `.html` artifacts, code comments, and commit messages should all be written in English, even when the subject matter is a Spanish thesis section — quote the Spanish text verbatim when citing it, but write the surrounding analysis in English. This rule is NOT in the repo's `CLAUDE.md`: it was added there once (commit 57b8374) and reverted at the user's request (eab871f/17b653c), so this memory file is its only home — which also means Codex sessions, which read CLAUDE.md via AGENTS.md, don't see it. A second exception, set by the user in September 2026: for the course final project on the AI-assisted history of this thesis (`claude_work/Proyecto_Final_IA/`), the final deliverables — the written report and the slide deck — are in Spanish, because they are presented at FCEN-UBA; that project's working files (PROGRESS, timeline, notes, question lists) stay in English. The general rule of thumb: anything handed in or presented at FCEN is Spanish, working material is English. The one deliberately ambiguous case is `Notas  - Latex/`, the author's informal working notes, which are already a Spanish/English mix — match whatever language a given note is already written in rather than forcing a switch there.
